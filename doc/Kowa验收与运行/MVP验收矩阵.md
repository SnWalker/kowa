# MVP 验收矩阵

状态：目标验收设计，尚未执行业务验收。更新：2026-09-25。

本文件拥有跨端验收场景，不拥有阶段状态。产品判据见 [MVP 流程](../wiki/design/mvp-delivery.md)，候选协议见 [契约草案](../research/mvp-contracts-draft.md)。只有实际实现后，才能将本矩阵映射为可执行命令与新运行证据。

## 1. 执行边界

自动测试使用隔离数据；真实 GitHub App 授权、任务派发、合并与部署按 AGENTS 的人工边界执行，除非当次任务明确另行授权。每次真实验收使用新的 WorkflowRun、任务和产物，记录代码/配置/数据水位，不能复用历史项目结果证明 Kowa 通过。

## 2. 目标场景

以下 A01—A28、B01—B12 和 C01—C08 共 48 项均为未执行的目标断言，不是已通过的测试数。

| ID | 场景 | 必须证明的行为 |
| :--- | :--- | :--- |
| A01 | 正常交付 | 知识绑定至人工批准合并、集成验证和关闭完整走通 |
| A02 | 第二业务仓库写需求 | 明确超出 MVP，不能静默执行 |
| A03 | 知识库不可达 | 阻断且说明原因，不冒充空知识 |
| A04 | 无相关知识 | 明确为成功读取后的空结果，保留人工确认 |
| A05 | 知识库更新 | 既有任务仍读冻结版本，新绑定有新快照 |
| A06 | 预填字段 | 预填 branch 等字段不能绕过人工确认 |
| A07 | 方案驳回 | 反馈、修订版本和重新批准可追溯 |
| A08 | 三轮返修耗尽 | 转人工，不自动放行或重置计数 |
| A09 | 必需测试失败 | 保持失败，不因 Task completed 或“继续”变通过 |
| A10 | 代码批准后新提交 | 旧证据不再自动用于新版本放行 |
| A11 | 重复人工提交 | 相同请求一次生效；冲突请求明确拒绝 |
| A12 | 过期人工请求 | 不应用于新版本或新节点轮次 |
| A13 | 续接进程重启 | 以持久答复恢复，不要求原进程常驻 |
| A14 | 旧租约/重复结果 | 不覆盖当前事实或重复推进 |
| A15 | 进度与结果 | progress 不能推进 DAG；业务不通过不等于执行异常 |
| A16 | 上游目录移除 | 下游隔离目录/进程仍能取到并校验产物 |
| A17 | 上传失败/摘要不符 | 不发布可消费结果，不返回假成功 |
| A18 | 模拟 QA | 明确标识，不能满足真实验证门禁 |
| A19 | 独立发布节点创建 PR 后响应丢失 | 查询后复用原对象，不重复创建；实际 PR 作者是 Runner 个人 gh 账号，Web 发起人另记 |
| A20 | GitHub 主动对账重试 | 重复观察或查询失败后恢复不重复推进；后期 Webhook 接入另验投递去重 |
| A21 | 乱序/漏失事件 | 对账后正确归集，不把旧状态覆盖新事实 |
| A22 | 合并时目标分支变化 | 验证明确的实际合并结果，不能拿旧基线假证通过 |
| A23 | 合并后验证失败 | 原项未关闭；人工确认修复关联新运行/新 PR |
| A24 | 取消与外部操作竞态 | 保留已发生事实，不能声称已回滚 |
| A25 | 已关闭后再次修改 | 创建关联新 WorkItem，不恢复旧交付 |
| A26 | 辅助知识建议失败 | 业务关闭与辅助失败分别显示，可单独重试 |
| A27 | 有效引用与清理竞态 | 不删除有效运行/关闭证据仍依赖的内容 |
| A28 | 权限与敏感信息 | Kowa API 越权拒绝、普通日志/Artifact 不主动泄漏秘密；Agent 可使用宿主个人 gh 是已选风险，不把 TaskSpec 误报为 GitHub 层硬隔离 |

### Workflow/Capability 扩展断言

来源见 [历史指南核对](../research/historical-guides-assessment.md) 与 [扩展设计](../research/workflow-capability-design.md)。这些断言用于未来目标红灯，本次只检查文档编号和链接。

| ID | 场景 | 必须证明的行为 |
| :--- | :--- | :--- |
| B01 | 定义格式错误 | 重复节点、未知字段/类型、缺必需值明确拒绝 |
| B02 | 控制依赖错误 | 不存在依赖或普通 DAG 环不可发布 |
| B03 | 数据绑定错误 | 非祖先引用、类型不符、被跳过上游缺必需输出不能静默为空 |
| B04 | 条件表达式错误 | 缺字段/类型错误不当作 false，不执行任意脚本 |
| B05 | 定义选择与覆盖 | 未知选择报错，同名同版本不同内容冲突；无隐藏本地覆盖 |
| B06 | 冻结依赖更新 | YAML/catalog/Prompt 更新不改变既有运行的依赖 |
| B07 | 能力注册不一致 | ID/版本/schema 不匹配或未授权环境不能派发；不做命名猜测 |
| B08 | 评审预算边界 | 初次评审及三次自动修订分别计数，耗尽转人工而非成功 |
| B09 | Join 与跳过 | 必需门禁不能因 non_gating、all_done 或 skipped 被绕过 |
| B10 | 非阻塞交互 | Worker 返回后不常驻等人，只有有效答复可续接 |
| B11 | 出站连接与重复派发 | 不需要控制面连接 Runner 入站端口；断连/重复交付不造成重复执行或越权 |
| B12 | 扩展与 golden | 新能力/工作流既有行为不退化；刷新 golden 不能替代语义测试 |

### 身份、版本与幂等补充断言

| ID | 场景 | 必须证明的行为 |
| :--- | :--- | :--- |
| C01 | 同一知识内容重复确认 | 内容可复用，人工确认事件不丢失；摘要无确认时间/自身 digest 循环 |
| C02 | 候选产物供审阅 | 可读取待确认内容，但未确认不能供下游自动执行 |
| C03 | 同幂等键不同内容 | 返回冲突，不能把内容摘要放进唯一键以绕过检测 |
| C04 | 跨 Workspace 访问 | 知道对象 ID/URL 仍不能读取或修改未授权的 Kowa 对象；另记录宿主 gh 对其他仓库可能有更大物理权限，不混称已隔离 |
| C05 | App 安装、Web 人员与机器 Git 身份 | 安装身份不等于登录用户或 Workspace 管理权限；A/B 是 Kowa 发起人，commit/push/PR 显示 Runner 个人 gh 账号，Agent 来源另存 |
| C06 | Web 授权或机器 gh 失效 | 撤销 Web/Kowa 权限后不派发新任务；机器 gh 登录/仓库权限失效时原生 Git/PR 失败并保留事实，不偷换 Web A/B 凭证；进行中的外部操作不能只靠 Kowa 撤权声称已停止 |
| C07 | Provider 输出/会话异常 | 截断输出拒绝；session 失效不丢人工答复或冒充续接成功 |
| C08 | 固定流程扩展 | MVP 无多模板选择；新定义可增加能力节点并保留旧运行冻结图 |

## 3. 所需证据

每个场景记录工作项/运行/节点/Task/HumanTask/Artifact 身份、被测代码与知识版本、命令及退出码、预期与实际行为、运行日志或外部事实、是否属于模拟数据。涉及重复/竞态必须记录事件顺序，不能只给最终截图。

纯绿地没有旧 Kowa 生产行为可冻结；阶段建立后从目标红灯开始，并在阶段与 record 说明 characterization 不适用。历史 demo 的两个测试仅是设计参考，不计入本矩阵通过数。

## 4. 判定口径

- PASS：对应目标有实际新证据，版本和身份匹配。
- BLOCKING_FAIL：Kowa producer/transition/consumer 违反明确合同或不变量。
- OBSERVATION_ONLY：确定性状态与证据合法，但模型质量或外部波动需要观察；不能用此标签忽略交付合同明确要求的失败门禁。
