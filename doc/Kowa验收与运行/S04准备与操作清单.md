## 2. Server 只读 PAT 的候选操作清单

本节是候选路线，不表示已创建凭证或完成生产配置。用户确认采用后再执行；方案变化写入经过批准的正式决定，S04 落实配置/秘密过滤与真实只读验收。

1. 在可访问目标仓库的主账号（例如 SnWalker）下，打开 GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens。无需第二评审账号的密码。
2. Resource owner 选择仓库 owner；Repository access 选 **Only select repositories**，只选 `kowa-sandbox`、`kowa-sandbox-knowledge`，不要选 Kowa 源仓或全部仓库。
3. 候选最小仓库权限：Contents: Read-only、Pull requests: Read-only、Checks: Read-only、Commit statuses: Read-only；Metadata 的必需只读权限保留。各观察端口落地时按真实 endpoint 校验权限，不增授 Administration/Actions/Secrets/Contents 写权限来制造通过。仓库保护配置的验收由 owner 独立核验，不要求 Server PAT 获得 Administration 权限。
4. 设置短期到期日（建议 30 天）并记录到期水位。GitHub 页面生成后仅存本机私密文件或系统凭证库；不得放进聊天、仓库、PR、日志或 Task 环境。
5. 下述命令只保存到候选本机路径，不表示现有 Kowa 已有对应配置消费者。它通过隐藏输入读取 token、不写 shell history 中的 token 值，并拒绝覆盖已有文件：

```bash
python3 - <<'PY'
import getpass, os
from pathlib import Path
p = Path.home() / '.config/kowa/github-read.pat'
p.parent.mkdir(parents=True, exist_ok=True, mode=0o700)
os.chmod(p.parent, 0o700)
token = getpass.getpass('GitHub read-only PAT (hidden): ').strip()
if not token:
    raise SystemExit('Empty token; nothing written')
fd = os.open(p, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
with os.fdopen(fd, 'w') as f:
    f.write(token + '\n')
print('Saved locally; no token printed')
PY
```

6. 只向接力会话说明“文件已准备”、路径及到期日，不提交 token 值。AI 可读取元数据并以专用短生命周期子进程做获准只读 endpoint 核验，输出 repository ID、PR/head、check/观察水位，过滤秘密。不能把 PAT 设成整个 Runner/Provider 继承的环境变量，也不能替换现有 gh 活动账号来制造通过。

创建步骤依据 [GitHub PAT 管理文档](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)。权限是否足够须按 S04/S05 的实际读取 endpoint 闭环；未做越权写入探测前，不宣称该凭证的写拒绝已验收。
