# Kowa Web 前端预览参考

本索引记录 Kowa 计划实现的 Web 界面视觉参考，供后续 AI 理解页面信息架构、布局、工作流状态和主要功能区域。图片用于设计与实现参考，不是现有产品代码或精确视觉规范；具体产品语义仍以 Kowa 当前设计文档和 `doc/common.md` 为准。

原始 PDF 与按页导出的 PNG 体积较大，只作为本地历史参考制品，不进入 Git 仓库。需要视觉核对时，应从团队约定的外部存储获取并按下述相对路径放置；缺少原始制品时，本索引只能提供信息架构线索，不能作为像素级证据。

## 目录内容与来源

- `Kowa web 预览1.pdf`：第一组原始 Web 页面预览，共 11 页。
- `Kowa web 预览1/`：从上述 PDF 按页直接提取的 11 张 PNG。文件编号与 PDF 页码一一对应，文件名概括了页面主要内容。
- `Kowa web 预览2.pdf`：第二组原始 Web 页面预览，共 13 页。
- `Kowa web 预览2/`：从上述 PDF 按页直接提取的 13 张 PNG。文件编号与 PDF 页码一一对应，文件名概括了页面主要内容。

PNG 保留了 PDF 内嵌图片的原始像素和 sRGB 色彩配置，没有二次缩放。源 PDF 本身存在一定屏摄模糊、摩尔纹和透视变形，因此不应仅凭图片确定精确字号、间距或色值。

## `Kowa web 预览1/` 描述

这组图片主要展示工作项详情页及其完整工作流视图，包括：

- 左侧全局导航、工作空间入口和页面顶栏；
- 工作流 DAG、节点状态、人工待办、执行日志和整体进度；
- 知识绑定、技术方案、D2C 设计还原、测试用例、测试报告；
- 代码变更、Pull Request（PR）、知识进化材料和整体评测等产物页签。

该组图片适合用于实现工作项详情页的总体布局、DAG 区域、运行状态反馈，以及不同阶段产物在同一页面中的组织方式。

## `Kowa web 预览2/` 描述

这组图片主要展示同类工作项详情页的节点配置与产物详情，包括：

- 工作流节点的 Metadata、System Prompt 和 Prompt 展示；
- 持久化知识、知识绑定、需求描述、技术方案与方案评审；
- 测试用例、测试报告、代码变更和部署预览；
- 失败状态、待处理事项与执行日志的并列呈现。

该组图片适合用于实现节点详情、提示词查看、阶段产物浏览、异常状态反馈和部署信息展示。

## AI 使用说明

后续实现 Web 界面时，应结合两个子目录的图片理解共同页面骨架与不同状态：优先按文件名定位目标功能，再查看相邻编号图片理解连续内容和状态变化。不要照搬图片中的示例业务数据、旧品牌文案、地址或环境信息，也不要将模糊截图当作像素级验收标准。
