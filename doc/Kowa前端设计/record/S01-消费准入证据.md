## 2. 逐操作的 Producer → Transition → Consumer

约定：`P` 为真正产生事实的 producer 入口（HTTP 路由到服务方法），`T` 为把持久事实映射为 Web 投影的 transition（服务端重新判定授权与版本），`C` 为本阶段将要实现的消费点。前端只消费已冻结字段，不新增语义、不复制授权、不缓存权威。

### 4.1 本地离线限制与替代证据

`scripts/check-*-contract.sh` 使用 `go run …/cmd/jv@v0.7.0` 做 schema 校验，该工具不在本机 Go 模块缓存中且本机当前无外网，故本地无法复跑这三个脚本；它们由 backend CI 的 `verify` 作业在联网环境执行（PR 最终 head 复核）。本阶段以 `jq` 逐字段断言（manifest 身份、`schemaSha256`、operation→`http`）与 `internal/interfaces/httpapi/*.go` 路由表逐条对照作为等价准入证据，并在 PR CI 上复核 owner 脚本的复跑结果。Go 工具链使用项目 `mise` 提供的 Go 1.26.9（`go build ./...` 在 `GOPROXY=off` 下 exit 0）。
