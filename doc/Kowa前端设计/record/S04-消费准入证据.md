## 2. 逐操作的 Producer → Transition → Consumer

约定：`P` 为真正产生事实的 producer 入口（HTTP 路由到服务方法），`T` 为把持久事实映射为 Web 投影的 transition，`C` 为本阶段实现的消费点。前端只消费已冻结字段，不新增语义、不复制授权、不缓存权威。

| :--- | :--- | :--- | :--- | :--- |
| workitem.detail | `GET /api/v1/workspaces/{workspaceID}/work-items/{workItemID}` | `internal/interfaces/httpapi/workitem.go:43`→`detail`（:112）→`WorkItemHandler.workItems.Get` | `session+member`；每次重读成员资格；跨 Workspace 与不存在不可区分（404→`RESOURCE_UNAVAILABLE`） | 详情页页头与「需求与验收」区：标题、`state`、`version`、`currentRunId`、需求/验收的版本与摘要；DAG 与历史区以 `currentRunId` 决定读取哪一条运行 |

## 3. 准入勘误（2026-10-16）

阶段文件原 `requires`（2026-10-01）共四条，经本 HEAD 逐项核对，**两条为不存在的死条目**：

| 原条目 | 分类 | 现行事实与处置 |
| :--- | :--- | :--- |
| `backend:S02 run.view`（`api/workflow-execution/v1/delivery.json`） | 规划漏项 + 文档漂移 | `CODE_CONFIRMED`：`api/workflow-execution/v1/` 下只有 `README.md`/`schema.json`/`examples/`，**没有 `delivery.json`**；`git ls-tree -r --name-only HEAD \| grep delivery.json` 全仓仅 8 个 manifest，不含此文件。原条目自标 `level=application`（backend:S02 的 `RunView` 是 Runner 侧应用生产者），本就不是 HTTP 消费面。处置：**移除**；运行/历史读取的真实 HTTP 载体是 `backend:S06 run.detail-history`（§2.3）。与 S02 的 G1 判定同例。 |
| `backend:S03 artifact.read`（`api/knowledge-artifact/v1/delivery.json`） | 规划漏项 + 文档漂移 | 同上：`api/knowledge-artifact/v1/` 无 `delivery.json`；原条目自标 `level=application`（应用内端口）。处置：**移除**；产物只读清单的真实 HTTP 载体是 `backend:S06 delivery.artifact-fixrun`（§2.3）。 |
| `backend:S05 workitem.detail` | 保留 | 真实存在且本阶段实际消费（§2.1）。 |
| `backend:S06 run.detail-history` | 保留 | 真实存在且本阶段**主载体**（§2.3）。 |

新增两条真实消费：`backend:S06 fixed.workflow`（§2.2，DAG 拓扑）与 `backend:S06 delivery.artifact-fixrun`（§2.3，产物/谱系）。

**依赖声明收敛**（文档漂移）：两个 `application` 死条目移除后，backend:S02 与 backend:S03 在本阶段**没有**可绑定的 HTTP 操作（其事实经 backend:S06 的组合投影到达浏览器，属间接影响而非直接消费绑定）。因此本阶段跨端依赖由 `backend:S02、backend:S03、backend:S05、backend:S06` 收敛为 `backend:S05、backend:S06`，并同步更新本端状态表 S04 行的前置依赖列与阶段文件的「前置与跨端依赖」节。这是合同绑定更新，**不重开任何 `DONE` 阶段**；与 S02 对 backend:S02/backend:S03 的处置完全同例。

`scripts/check-stage-contracts.py` 强制「状态表前置依赖 == 阶段文件声明的本端前置 + 跨端阶段」且「每个跨端依赖必须有 requires 条目」，因此上述收敛是准入的**必要条件**，不是可选项。
