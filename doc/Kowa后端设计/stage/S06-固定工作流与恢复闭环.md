# S06：固定工作流与恢复闭环

> 状态只在总体设计维护；执行事实进入 record/S06.md。

## 阶段设计依据

前序模块提供独立能力，本阶段必须把唯一固定流程、汇合、返修预算和恢复命令组装成一条可自动验证的交付链。

## 现行勘误（仅 REOPENED 时填写）

不适用。

## 唯一工程目标

发布并运行固定 MVP WorkflowDefinition v1，完成从需求/知识到关闭前全部节点的自动化集成与失败恢复。

## 前置与跨端依赖

- 本端前置阶段：S05。
- 跨端阶段：无。
- 共享契约 owner：backend:S06。
- 冻结契约及版本：kowa.fixed-workflow.v1。

## 必读

MVP 流程、执行架构、生命周期、全部 S01—S05 冻结合同、fixed-workflow 候选、验收 A01/A08—A15/A23—A26/B01—B12/C08。

## 核心文件与修改范围

### 核心文件

内置定义、发布/编译入口、应用编排、返修影响计算、恢复命令、跨模块集成测试和 golden。

### 允许修改

固定 DAG、能力目录引用、输入绑定、Join、三轮返修、人工恢复、Retry/Rerun/取消、修复运行和知识建议异步分支。

### 明确禁止

多模板 UI、任意 DAG 编辑、Replay 操作、多仓父子编排、绕过前序模块接口的特例代码。

### 并行写入范围

独占固定定义、集成编排及 kowa.fixed-workflow.v1；不重新拥有各模块合同。

## 当前问题与证据

- CONFIRMED：固定流程节点责任和返修/关闭政策已批准。
- CODE_CONFIRMED：候选 17 节点 JSON 可解析但不是运行实现。
- DATA_CONFIRMED：无 WorkflowRun。
- STRONG_INFERENCE：前序深模块可通过小编排接口组合。
- HYPOTHESIS：实际节点粒度和部分超时默认值需红灯验证。
- 文档与源码差异：外部 HumanTask 与 GitHub 请求修改返修尚未机器化冻结。
- 证据不足项：完整断点恢复和取消竞态。
- 固化旧错误的测试：无。

## Producer、Transition、Consumer

固定定义和用户命令生产运行意图；编排器跨模块转换；Runner、Web 投影、审计和最终验收消费。

## 本阶段新增或修改的模型

FixedWorkflowDefinition/CompiledPlan v1、RevisionRegion、RecoveryCommand；不复制各模块领域状态。

## 约束

普通依赖无环；返修显式有界；必需门禁不可 skipped/all_done 绕过；旧结果保留但失效；一项 WorkItem 只有一条推进运行。
