## 当前问题与证据

- CONFIRMED：机器账号、真人 Review、人工合并和外部未知语义已冻结。
- CODE_CONFIRMED：无实现。
- DATA_CONFIRMED：无真实 PR/Review/merge 证据。
- STRONG_INFERENCE：持久外部操作意图加只读对账可处理结果未知。
- HYPOTHESIS：同机 gh 只读适配器、轮询退避和仓库规则细节待实测。
- 文档与源码差异：候选 schema 未覆盖完整交付查询面。
- 证据不足项：真实 Reviewer 权限、CI 来源与 merge OID 行为。
- 固化旧错误的测试：无。

## Producer、Transition、Consumer

用户/Runner/外部 GitHub 生产答复与事实；控制面对账并判断适用性；Workflow、Web、审计和关闭用例消费。

## 本阶段新增或修改的模型

HumanTask/Response、ExternalOperation、GitHubObservation、GitOperationEvidence、VerificationEvidence、ClosureEvidence；提醒解决不等于门禁通过。

## 约束

head/OID 漂移使旧证据失效；Reviewer 非 PR 作者；未知先查再重试；关闭与有效运行成功同一事务；知识建议/离线评测不阻塞关闭。
