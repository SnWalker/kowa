### 领域规则（冻结语义）

- **采集前脱敏，唯一权威**：`observability.Redact` 是采集前过滤器；S05 的 `gitremote.Redact` 保留导出符号并委托到它（行为由 characterization 冻结）。事件、日志字段、OTLP span 属性、spool 记录一律先脱敏；脱敏后仍命中凭据模式的值**拒绝写入**（fail closed），不是写进去再隐藏。完整用户输入与 prompt 正文永不进入事件，只允许 digest 与引用。
- **稳定关联 ID，不改既有 wire**：`TraceContext` 由既有身份（run/nodeRun/task）确定性派生，Server 与 Runner 在同一 attempt 上得到同一 trace id，且**不向 S02 任务 wire、S04 transport、任何冻结 schema 增加字段**。派生使用 SHA-256 截断并保证非全零。
- **心跳不等于业务进度**：`contactability` 水位只由 Runner 心跳写入，`business_progress` 水位只由节点/Task 进展写入；健康投影分别陈述，联系正常不得让停滞的运行显示为在推进。
- **旧观察不冒充新事实**：外部观察水位的成功时间只在读取成功时前进；读取失败只推进尝试/失败时间并立即把新鲜度降为 `stale`/`unknown`。不新增"最后一次已知事实"的语义（既有 S05/S06 语义不变）。
- **同步门禁与异步评测分离**：`Mode=sync_gate` 的评测必须取得后端确认，后端不可用即"未满足"并记录恢复条件，不降级、不假装通过；`Mode=async` 的后端失败只记录状态与重试，**永不**改变交付状态。运行成功与 WorkItem 关闭仍只由 S05 `evaluation.AtomicCloser` 单事务提交。
- **Langfuse 不是状态真源**：Adapter 只有写入与健康探测，没有任何读回路径；Kowa 的任何决定都不读取后端数据。
- **观测不新增持久权威**：spool 丢失或损坏不影响任何业务事实；spool 校验失败按"观测缺失"记录，不阻断业务。
- **备份一致性与恢复**：备份从一致性点取得，`BackupManifest` 逐组件记录 sha256；恢复前先校验摘要，不匹配一律 fail closed；恢复**不删除**仍被运行或关闭证据引用的内容（A27 语义由 S03 拥有，本阶段只做不破坏的负向断言）。
- **隔离边界如实声明**：单 macOS 账号不是硬隔离；任务目录与宿主可见范围用**假凭证**实测并如实记录（不得声称硬隔离、不得用真实令牌做越界试验、不得执行生产部署）。
- **RPO/RTO 实测后记录**：只记录实测值与测量方法；未测项写"未测"，不写 SLA。
